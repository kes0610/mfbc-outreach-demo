# MFBC Outreach Assistant

A tool for the Madison Fashion Business Collective (MFBC) to draft sponsorship,
speaker, and partnership outreach, estimate the chance of a reply from past
history, and track follow-ups — built by a UW–Madison Information Science
student as a club project and portfolio piece.

**Status:** Phase 1 only. The Outreach History section below is built; email
drafting, the reply-likelihood model, the follow-up tracker, and the reply
assistant have not been built yet.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run Home.py
```

The app stores data in `data/outreach.db` (SQLite), which is gitignored —
real MFBC outreach history never leaves your machine or gets committed.

## Try it without real data

```bash
python seed_synthetic.py
```

This writes `sample_synthetic_outreach.csv` — clearly-labeled fake data with
the same schema as the real app. Import it from the Outreach History page's
"Import CSV / Excel" tab to try every feature without needing MFBC's actual
history.

## Outreach History — data schema

Each record:

| Field | Notes |
|---|---|
| company | required |
| contact_name, contact_role | optional |
| ask_type | sponsorship / speaker / partnership / other |
| date_sent | |
| sender | which member sent it |
| is_follow_up | bool |
| has_uw_mfbc_connection | bool |
| has_prior_relationship | bool |
| email_text | optional, full text of what was sent |
| notes | optional, free text |
| outcome | no_reply / replied / declined / meeting_booked |
| reply_date | set when outcome implies a reply |

## Data safety

- Every add, edit, delete, and import commits to SQLite immediately — there's
  no manual save step, and a "Saved HH:MM:SS" indicator confirms each write.
- A backup copy of the database is made automatically once per day and before
  every import, into `backups/` (also gitignored).
- Deleting rows in the edit table requires an explicit confirm step.
- Every import can be undone in one click, as long as nothing newer has been
  imported since.
- "Export to CSV" on the History page always gives you a plain-text copy of
  everything in the database.

## Model evaluation and limitations

Not written yet — there is no trained model in this phase. When Phase 2
(reply-likelihood model) is built, this section will report actual AUC,
calibration, and feature importance from real evaluation, not placeholder
numbers. If the real dataset turns out too small for a reliable model, that
will be reported here plainly, with a High/Medium/Low fallback used instead.

## Privacy

Real outreach data (the SQLite database, CSV/Excel exports, and backups)
stays local and is excluded from version control via `.gitignore`. Only the
synthetic sample data generated by `seed_synthetic.py` is meant to be shared
or committed.
